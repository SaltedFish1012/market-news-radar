## 接入方式选择

采用 SEC 原始披露，避免新增付费聚合账户。付费聚合服务可以减少解析和证券代码映射工作，但引入密钥、计费及供应商依赖；只筛选现有 SEC RSS 最简单，但无法可靠展示持仓变化或交易金额。第一版因此选择官方 submissions / filing XML，沿用本机 SEC 联系标识。

依据：[EDGAR APIs](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)、[开发者资源与 Fair Access](https://www.sec.gov/about/developer-resources)、[13F FAQ](https://www.sec.gov/rules-regulations/staff-guidance/frequently-asked-questions-about-form-13f)、[Form 4 说明](https://www.sec.gov/file/form4pdf)。

## 聪明钱页面

导航增加“聪明钱”，路径 `/smart-money`。页面有“机构持仓”和“内部人交易”两个视图，可按已关联股票、机构、报告期、交易类型筛选。行情／新闻页右侧 X 栏下方增加最近披露摘要，跳转到详细页。

第一版先做采集、展示与筛选，聪明钱披露不自动触发手机通知或 AI 调用。原新闻／X／价格通知流程保持原设置。

### 机构持仓

- 设置中维护机构名称和数字 CIK，最多 20 个；提供 Berkshire Hathaway（CIK 1067983）的可选示例，不把所有机构默认加入用户跟踪。
- 读取指定机构的 `13F-HR`、`13F-HR/A`，保留 accession、原始申报链接、报告期、披露日期、接收时间、修订类型和数据完整状态。`13F-NT` 不当成持仓清单。
- 完整获取封面及信息表后才提交一个快照。展示发行人、证券类别、CUSIP、股数、披露市值；期权 put/call 和债券本金与普通股票分别展示。
- 只比较同机构相邻报告季度的完整、可解释快照，按 CUSIP／证券类别／put-call／股数类型匹配；给出新增、增持、减持、退出和股数变化。第一次或缺失上季时显示“缺少比较基准”，不把全部持仓标为新增。
- “持仓变化”仅表示两个报告期的披露差异，不计算实时净流入或宣称实际买卖时点。13F 通常按季披露并存在申报延迟，页面始终显示报告期和披露日。
- `NEW HOLDINGS` 修订为补充、`RESTATEMENT` 为重述；无法判断或无法组成完整快照时展示修订原件并停止差异推断，不能把缺失行当成清仓。
- 第一版只解析 2023-01-03 以后以美元为单位的申报；更早文件只展示链接及不支持的单位说明，避免旧千美元数值误乘／误除。
- CUSIP 到股票内部代码通过明确配置的映射关联；未映射时展示发行人和 CUSIP，不靠名称相似度猜代码，不强行关联自选股。

### 内部人交易

- 追踪统一自选中的美股股票，使用 SEC 官方 ticker／CIK 索引及必要的显式代码映射；ETF、指数及其他市场显示范围说明。
- 读取 Form 4／4-A 原始 ownership XML，分别保留发行人、报告人、身份、交易日、披露日、交易代码、股数、单价、交易后持股、直接／间接所有权、足注及 10b5-1 标记。
- P／S 表示买入／卖出，可包含公开市场或私人交易；没有足注证据时不再细分。A 授予、M 行权、F 扣股缴税、G 赠与和其他代码独立显示，不归为主动买入／卖出。
- 非衍生和衍生交易分开。只有明确数值价格才计算 `股数×单价`；价格区间、足注价格或缺失价格显示未知，不伪造精确金额。
- 4-A 以修订件展示并关联原报告范围；不保证可以直接覆盖原交易行，不将同一修订当成新的主动交易。

## 数据与运行

- 新增独立 `sec_filings`、`institution_positions`、`insider_transactions` 和采集进度表；迁移可重复执行，不修改旧新闻记录。申报 accession 去重，事务提交所有已验证行及采集进度。
- 新增 SEC 客户端与 XML 解析模块；固定允许 `data.sec.gov`／`www.sec.gov`，校验 accession、CIK 和文档路径。限制响应大小、拒绝 DTD／实体，避免任意外部 URL 或 XML 实体请求。
- 使用现有 `SEC_CONTACT` 作为可识别 User-Agent；未配置联系邮箱时暂停新采集并显示设置入口，已有归档仍可读。
- 新设置：聪明钱启用开关（默认关）、轮询间隔（默认 900 秒，范围 300–86400）、机构列表、CUSIP 映射。首次机构读取最多覆盖最近两个报告季度；内部人首次归档最近 90 天，状态明确记录覆盖范围。
- SEC 请求串行限速最多每秒 2 次；403／429 按 Retry-After 或退避处理，单个机构失败不阻止其他机构，禁止绕过上游限制。旧进度不因错误或热配置重启丢失。
- 聪明钱专属设置的热配置只重启聪明钱任务；统一自选变化也重启它，共用 SEC_CONTACT 变化保留现有 RSS 重启规则。取消后的旧任务不得再提交数据。无关的 X／行情／通知任务继续运行。
- 新增认证后的 `/api/smart-money/overview`、`/api/smart-money/holdings`、`/api/smart-money/insiders`；状态 API增加覆盖范围、上次成功、错误和重试时间，均不暴露 Token 或联系标识。
- 概览只读已归档数据，不为每次页面刷新重新抓上游；部分来源失败返回各来源状态与可用旧数据。

DOM 验证普通新闻与 X 分离、独立读取、作者和完整原文安全渲染、账号切换竞态、preview 不归档、未配置提示、聪明钱标签／日期／筛选和来源链接。浏览器验收桌面及 390px 窄屏，不产生横向溢出。
