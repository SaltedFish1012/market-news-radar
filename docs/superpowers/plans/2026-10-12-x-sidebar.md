# X Sidebar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 X 用户言论独立放到研究工作台右侧，提供 @aleabitoreddit 的只读测试入口。

**Architecture:** 复用现有 XClient、稳定作者身份、归档与推送流程，增加独立数据库查询和临时预览接口。右栏拥有独立状态及请求代次，不等待行情或普通新闻；设置页隐藏，窄屏排列在主内容下方。本计划可以先独立交付，SEC 功能由另一份计划增加。

**Tech Stack:** Python 3.12、FastAPI、SQLite、httpx、原生 JavaScript/CSS、pytest、Node 24.19/jsdom 29.1.1；不增加依赖。

**Spec:** `docs/superpowers/specs/2026-10-12-x-sidebar-smart-money-design.md`（X 右侧栏、数据与运行、验收）。

## Global Constraints

- 保留原数据库、配置、登录、四时段和现有推送行为；继续使用 `codex/market-sessions-x` 工作树。
- 工作台各研究页面显示 X 栏，设置页隐藏；桌面约 320px，窄屏在主内容下方，无横向溢出。
- 普通新闻仅展示非 X 新闻；X 查询上限 100，preview 最近最多 10 条，输入预填 `aleabitoreddit`。
- 明确标记“X 用户言论”；保留作者名、@username、稳定 ID、发布时间、完整原文、原文链接、编辑及引用角色。
- preview 不写新闻、账号别名、游标、通知或设置，不自动轮询；页面加载不触发 preview。提示官方读取可能收费。
- overview、quotes、X 归档、preview 各有独立代次；切换账号、页面或退出后旧响应不能覆盖当前结果；所有上游文本 escape。
- Token 未配置时只显示设置提示；公开嵌入历史帖不当成最新时间线或生产归档，不发送测试通知。

## Review Focus

1. 大量 X 归档挤掉普通新闻：SQL 在 LIMIT 前分流；Task 1 `test_news_filter_precedes_limit`。
2. 作者改名或旧用户名被复用：仅按本机确认的稳定 ID/别名查询；Task 1 `test_x_archive_uses_confirmed_identity`。
3. preview 返回数据或错误后意外修改归档：成功、402、429 都保持所有相关表不变；Task 1 `test_preview_is_read_only`。
4. 慢请求遇到账号/页面切换或退出：丢弃旧结果且新请求可完成；Task 2 `old X responses cannot replace current view`。
5. 长文、恶意作者文本、未配置 Token：完整安全显示、清楚提示、不开启收费读取；Task 2 `long speech is escaped and preview requires a click`。

### Task 1: 独立归档查询与只读账号预览

**Files:** Modify `app/db.py`, `app/main.py`; Create `app/x_views.py`, `tests/test_x_views.py`; Test existing `tests/test_x_storage.py`, `tests/test_x_runtime.py`。

**Interfaces:**
- Consumes: `DB.x_user(username: str) -> dict | None`、`app.x_news.XClient(token, transport=None)`、`resolve_user(username)`、`fetch_posts(user_id, account, *, since_id=None, next_token=None, max_results=100)`、`parse_posts(data, user)`、`close()`；均为现有接口，异步方法照原定义调用。
- Produces: `DB.news_rows(*, limit: int, source_type: str='all') -> list[dict]`，`source_type` 仅 `all/news`；`DB.x_posts(*, limit: int=100, username: str | None=None) -> list[dict]`；`DB.x_accounts() -> list[dict]` 返回 `{id,username,name}`。
- Produces: `XPreviewRequest(BaseModel)` 仅 `username: str`，复用 XAccount 的用户名验证；`async preview_posts(client: XClient, username: str) -> dict` 返回 `{state:'ok', user:{id,username,name}, items:list[dict]}`。每条展示行有 `source_type:'x'`, `raw_text`, `published_at`, `url`, `x_metadata`（parse_posts 字段），不生成数据库 id。
- API: `GET /api/news?limit=200&source_type=news`；默认 `source_type=all` 保持旧调用兼容。`GET /api/x/posts?limit=100&username=...` 返回 `{items,accounts}`，limit 1–100，未知别名返回空列表。`POST /api/x/preview {username}` 返回 `{state,items,user?,kind?,detail?,retry_at?}`；缺 Token 为 `not_configured`，上游错误为 `error`，这两类返回 200 供 UI 展示；认证失败 401、输入失败 422。三者均沿用 `Depends(auth)`。
